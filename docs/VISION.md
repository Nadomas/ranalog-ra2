# Vision — ra2-analog

## Цель

Создать игру про конструирование боевых роботов, их настройку, тестирование и последующие физические бои.

Духовный наследник **Robot Arena 2**: не клон, а современная интерпретация той же инженерной фантазии.

## Ценность

Главная ценность — **глубина и свобода инженерного конструирования**, а не количество контента.

Игрок должен чувствовать себя одновременно:

- **инженером** — проектирует машину под физику и ограничения;
- **программистом управления** — собирает систему ввода из действий и групп;
- **пилотом/тактиком** — использует результат в бою.

## Scope

Игра **не** должна быть огромной по объёму контента.

Основная сложность сосредоточена в системах:

- construction;
- components;
- control binding / groups;
- physics;
- damage;
- multiplayer;
- battle simulation.

Контент — относительно компактный, но **системно глубокий**.

## Что не в core (пока)

- Экономика и карьера — опциональный слой поверх core (см. [TECHNICAL_PRINCIPLES.md](TECHNICAL_PRINCIPLES.md)).
- Финальный набор PvP-режимов — не зафиксирован.
- Production engine зафиксирован: **Unity**. Конкретные packages/physics/netcode внутри Unity — через эксперименты ([UNITY_ENGINE.md](UNITY_ENGINE.md)).

## Критерий успеха раннего этапа

Доказать, что можно:

1. собрать робота из модулей с осмысленной физикой;
2. настроить управление действиями/группами;
3. мгновенно тестировать;
4. синхронизировать физический бой в сети на уровне MVP-архитектуры.
